# Инструкция по установке скрипта для Битрикс24

Этот скрипт изменяет интерфейс Битрикс24, делая его удобнее. Установка займет не более 2 минут.

## Шаг 1. Установка расширения в браузер
Для работы скриптов необходимо расширение **Tampermonkey**. Оно служит «двигателем» для запуска ваших улучшений.

**[Скачать Tampermonkey](https://www.tampermonkey.net/)**

---

## Шаг 2. Важная настройка для Chrome (и браузеров на его базе)
В современных версиях браузеров (Chrome, Edge, Яндекс) нужно включить **Режим разработчика**, иначе расширение не сможет запустить скрипт.

1.  Скопируйте это в адресную строку браузера: `chrome://extensions` и нажмите **Enter**.
2.  В правом верхнем углу найдите переключатель **«Режим разработчика»** (Developer mode) и **включите его**.
3.  **Перезагрузите браузер** (полностью закройте и откройте снова).

> **Внимание:** Без включения этого режима в Chrome скрипт работать не будет.

---

## Шаг 3. Установка самого скрипта
Теперь можно установить само дополнение в «двигатель»:

1.  Нажмите на эту ссылку: **[УСТАНОВИТЬ СКРИПТ](https://github.com/AlphaCNC01/bitrix_interface_modifier/raw/refs/heads/main/bitrix_interface_modifier.user.js)**
2.  Откроется новая вкладка с кодом и интерфейсом Tampermonkey.
3.  Нажмите кнопку **«Установить»** (или «Install»).

---

## Шаг 4. Проверка работы
1.  Откройте ваш Битрикс24 (или обновите страницу, если она уже открыта).
2.  Нажмите на иконку «пазла» (расширения) в верхнем углу браузера.
3.  Найдите **Tampermonkey** и нажмите на иконку «булавки», чтобы закрепить его на панели.
4.  Нажмите на саму иконку Tampermonkey (черный квадрат). В выпадающем меню вы должны увидеть название скрипта и зеленый переключатель **«Включено»**.

---

## Часто задаваемые вопросы (FAQ)

**В: Это безопасно?**  
О: Да, скрипт работает только локально в вашем браузере. Он не имеет доступа к вашим паролям и не передает данные на сторонние серверы.

**В: Скрипт не работает, что делать?**  
О: Проверьте, включен ли «Режим разработчика» (Шаг 2). Если он включен, попробуйте обновить страницу Битрикс24 через **Ctrl + F5**.

**В: Как обновлять скрипт?**  
О: Tampermonkey автоматически проверяет наличие новых версий раз в сутки. Если автор обновит код на GitHub, изменения подтянутся сами.
